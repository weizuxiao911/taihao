# 裁剪决策全景-draft

- L1 保留(两套内核都开): 网络基线 / 文件系统 / 安全沙箱 / 调度cgroup / 启动平台 / 块设备IO
- L2 CI裁(仅CI内核裁): 接入位设备 / 网络设备 / 调试可观测 / 文件系统 / IPC
- L3 全裁(两套都裁): 古董协议 / 真机FS / NPU-GPU-VPU / 电源内存 / 遗留IPC
- L4 可选(按需开启): 沙箱补充 / 调试build / 内存压缩 / FS扩展

## 连线
- 框对框(默认): L1→L2→L3→L4 垂直,从源框底中点指向目标框顶中点

## 外框
- 无外框(4 层独立,各为一种决策类别)
