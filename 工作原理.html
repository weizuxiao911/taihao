双回路: 慢决策 × 快控制 (频率分离)
慢回路 · 决策 (LLM) LLM 接入层 → Pi Agent 决策 (Agent Loop / SKILL 推理)
· 输出: 目标与模式, 频率 ≤1Hz
· 延迟: 200ms ~ 3s, 不足以承担 10ms 周期 PWM 控制
快回路 · 控制 (实时) 高频实时回路 C / Rust, 10~100Hz
· 推进器 / 姿态 / 避障回路由 Linux Core 内进程直接承担
· 10ms 级周期, 不经过 LLM
分界Pi Agent 只下发目标与模式 (≤1Hz); 100Hz 控制回路全程 C/Rust, 决策与控制物理隔离

① 网联对接: 上电激活 → 中台调度通信模块建立远程连接 → 接收任务

⑤ 结果回传: 经中台调度通信模块上报执行结果

太昊 OS · 安全准则 · 隔离栈 · 双链路 · 固件三分区

页面 3/4 · B5 横向 · 两条核心安全准则约束 LLM 与硬件的边界
两条核心安全准则

① LLM 不直接下场做实时控制

100Hz 推进器 / 姿态 / 避障回路由 Linux Core 内 C/Rust 高频进程承担;
Pi Agent 仅以 ≤1Hz 下发目标与模式;
LLM 回路延迟 200ms~3s, 不足以承担 10ms 周期的 PWM 控制。

② LLM 不绕过 HAL 网关直接驱动硬件

CORE → HW 必须经 Pi Agent SKILL 调用触发;
所有 SKILL 调用必经 HAL 网关白名单校验 + 审计日志落盘;
Pi Agent 跑在受限 namespace、无 capabilities;
HAL 网关持有 CAP_SYS_RAWIO / CAP_NET_ADMIN。

OTA 升级采用 A/B 双系统分区 + 失败回滚; 业务与配置分区升级后保留, 厂商资产不因系统升级丢失
